# ml_session_signal_type_classification
Файлы содержат решение для соревнования: [signal-types-classification](https://www.kaggle.com/competitions/signal-types-classification/overview). В нем даны сигналы, которые необходимо кластеризовать на 3 класса: гамма-кванты, нейтроны и сигналы неподдающиеся классификации. 

Основной файл - `ml_session_exp_small.ipynb` - содержит в себе полное решение, но модифицирован для минимальных затрат памяти, так как github не всегда может отрендерить ноутбук (видимо зависит от нагрузки). На случай, если он показывает ошибку `"Unable to render code block"` в репозитории лежит `ml_session_exp_small_no_outp.ipynb` - сохраненный без результатов выполнения ячеек.
В случае, если он тоже не грузится, получить доступ можно по ссылке в nbviewer [ссылка](https://nbviewer.org/github/IlyaSamoylov/ml_session_signal_type_classification/blob/main/ml_session_exp_small.ipynb) или по ссылке на гугл диск ([ссылка](https://colab.research.google.com/drive/1ymirh3AWMQaQ2nyM9ImgJGmmLQ4OQiFJ?usp=sharing])).
